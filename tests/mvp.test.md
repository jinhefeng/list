## 当前开发顺序

按以下顺序推进，并在每一步完成后更新对应状态：

1. A-01、A-02、B-01、B-03、B-06：完成最小记录闭环。
2. B-05、B-07、B-08：补充照片和可选信息。
3. C-01、C-02、C-03：完成菜单选择和自定义饮品。

5. D-01 至 D-05：接入营养数据和统计。

- 修改后 `npm test`：28 项中 22 通过、6 失败，失败项目与修改前一致；没有修改旧用例或产品规则来掩盖失败。
- JavaScript 语法、页面注册和 JSON 检查通过。使用已安装微信开发者工具自带的 `wcc` / `wcsc` 编译修改的 WXML / WXSS 通过。
