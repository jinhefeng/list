# 每日饮品记录小程序

一个原生微信小程序 MVP，用于个人记录每天喝过的饮品，并查看有数据支持的能量、糖量和咖啡因摄入。

## 本地开发

1. 使用微信开发者工具打开本目录。
2. 项目配置中的 `touristappid` 是占位值；提交或上传到微信前，替换为自己的小程序 AppID。
3. 在终端运行 `npm test`，执行饮品记录业务逻辑和页面表单行为测试。

## 当前功能

- 今日饮品记录和按日期筛选的历史记录。
- 菜单品牌/款式搜索、手动填写规格、甜度、冰度、小料、时间、地点和备注。
- 从相册或相机选照片，并在设备内保存。
- 自定义品牌与饮品；用户输入的营养数值标记为估算值。
- 按精确匹配的规格与选项展示官方数据或估算数据；缺少匹配数据时显示“暂无数据”。
- 今日能量、糖量、咖啡因汇总，以及数据来源计数。
- 编辑和删除自己的本地记录。

## 数据范围

内置菜单只含少量示例品牌和款式，条目标记为待核验，且没有官方营养数据。菜单结构支持地区、来源、更新时间、下架状态和不同选项的营养变体。正式发布前需要按实际目标市场核验和扩充菜单数据。

记录、菜单和照片目前仅保存在运行小程序的设备上。没有账号登录、云端存储或跨设备同步。
